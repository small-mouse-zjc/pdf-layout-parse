# 版面解析算法说明

本文件说明 `scripts/pdf_struct.py` 为什么能得到正确阅读顺序，以及每个阶段的判据与参数。目标是让他人能在不看代码的情况下复核逻辑、定位失败原因。

## 0. 总览

```
pdftohtml -xml  ──► 字形项(坐标/字号/字体族)  ──►  公式识别（先从流中摘除）
                                        │
                                        ├─►  行装配 pass 1（保守）──► 栏缝检测
                                        │                              │
                                        └─►  行装配 pass 2（放宽，栏缝受保护）
                                                                       │
                          分带+分栏排序  ◄──────────────────────────────┘
                                │
        段落重建（缩进/短行/续句）──► 语义抽取（题名/作者/摘要/章节/图表/公式/文献）
                                │
                        证据绑定（页码 + bbox）──► result.json
```

## 1. 字形项与字号

- 后端：`pdftohtml -xml -hidden -i`。每个 `<text>` 元素给出一段同字体文本及其包围盒；`<fontspec id size family>` 给字号与字体族。
- **陷阱**：poppler 的 `fontspec` 表是**文档级**的，只在某字体首次出现时输出。若按页解析，后续页的字号会全部丢失（本项目初版即因此把 15pt 正文误判为 10pt，导致标题、作者、标题层级全部错位）。实现上先扫全文建立 `id → (size, family)` 表，再解析各页。
- 正文字号 `body` = 按字符数加权的众数字号（剔除占比 <2% 的稀有字号）。全部阈值都以 `body` 为基准，避免不同排版尺度下硬编码像素值。

## 2. 行装配（两遍）

**pass 1（保守，gap ≤ 1.25 em）**：同一基线带内、水平间隙不超过约 1.25 个字宽的字形项合并为一行。旋转文字（宽度退化为 0）直接丢弃——arXiv 侧边水印属于此类。

**pass 2（放宽，gap ≤ 6 em，且受栏缝保护）**：行内数学（`H(x)`）与两端对齐产生的大空格需要更大间隙才能接回原句。为此：
- 若间隙区间与已检出的栏缝相交 → 拒绝合并（防止把左栏行尾与右栏行首缝在一起）；
- 若间隙 > 2.2 em 且两侧字号差异 > 5% → 拒绝合并（图中的 `3x3 conv, 128` 标签不得混入正文）。

顺序：**先 pass 1 求栏缝，再用栏缝约束 pass 2**。反过来做会被合并后的跨栏长行"抹平"栏缝，这正是许多解析器在含跨栏标题的页面上失效的原因。

## 3. 栏缝检测（本 Skill 的核心）

判据基于**正文级字号的行的几何**，而非像素覆盖：

1. 取该页正文字号（±6%）且位于上下 5.5%–94.5% 之间的行；若不足 8 行（如参考文献页用小字号），改用该页出现最多的字号。
2. 对行左边界 `x0` 做一维聚类（容差 1% 页宽，簇内 ≥8% 行）→ 得到各栏的左边距 `a < b < …`。
3. 对每一对 `(a, b)`：
   - 左簇中"在本栏内结束"的行（`x1 ≤ b`）必须 ≥50%，否则视为单栏排版（该判据淘汰了单栏页上由作者地址、缩进块造成的伪栏缝）；
   - `g0 = 左簇闭合行 x1 的 90 分位`（忽略少数通栏行），`g1 = b`；
   - 栏缝宽度须在 `0.4%–11%` 页宽之间；
   - 两侧行数各 ≥10%，且各 ≥6 行。
4. 重叠候选去重，保留全部互不重叠的栏缝（支持三栏及以上）。

为什么不用"空白列"或"覆盖率为 0"：跨栏标题、通栏表、通栏摘要会让栏缝的覆盖率不为 0；而稀疏页面上"覆盖率为 0"的区域过宽。上界 11% 页宽同时排除了"右侧参差造成的假空白"。

## 4. 阅读顺序：先分带，再分栏

对每页的有序行集合：

1. 判定每行所属栏号；跨过任一栏缝的行标记为 **spanning（-1）**。
2. 按 y 排序，spanning 行各自开启一个新"带"（band）；带之间的普通行按栏号归组。
3. 每个带内：先左栏自上而下，再右栏自上而下；spanning 行原位输出。

这样标题、通栏表、通栏图注不会被拆到两栏里，栏内也不会出现上行接下栏。相较递归 XY-cut，该方案对"通栏元素贯穿页面"更稳健，且复杂度线性。

## 5. 页眉、页脚、侧边水印

三类信号组合判定（都在正文行池之外先行剔除）：

1. **位置**：`y1 ≤ 9%` 页高 或 `y0 ≥ 88.5%` 页高；侧边 5.5% 内且宽度 <3% 页宽。
2. **形态**：纯页码（`^[-–—\[\]()]*\d{1,4}[-–—\[\]()]*$`）、`Page 3 of 12`、卷期年（`Vol. 12, No. 3, 2020`）。
3. **跨页重复**：去掉数字后归一化的字符串，在同一位置带内出现于 ≥35% 的页面 → running head / 期刊横幅。

保护规则：首页且字号 ≥1.35×正文的块不判为页眉（避免误删大标题）。

## 6. 图内矢量文字与图注

- 图注起点判据：行首匹配 `^(Figure|Fig\.?)\s*N[.:|]` / `^(Table|Tab\.?)\s*N[.:|]`，且**其上方紧邻行不以句末标点结束则视为正文交叉引用**（排除 "… as shown in Fig. 4. First, …" 这类误判）。
- 图注续行：同栏、同字号（±10%）、行距 <0.85 行高、水平重叠 ≥45%；另对"被大空格拆散的同一基线片段"做邻近回收。
- 图内标签掩蔽：自图注首行向上扫描同一 x 带，凡字号不等于正文、或为短词（<5 词）的行即判为图件标签并掩蔽，遇到正文字号的长行、或标题级字号即停止；落在 `<image>` 包围盒内的行一律掩蔽。

## 7. 表格网格

1. 区域：表题下方（若下方无内容则上方）同一 x 带内、行距 <3.2 行高的连续非正文行；遇到正文长行、下一个题注或标题即止；支持"表体在下一页"的续接。
2. 行：同基线的多个行对象合并为一行（通栏表被栏缝切开的两半在此重组）。
3. 单元格：按原始片段间隙切分（阈值 0.5 em）；跨行合并的单元格在 Markdown 中表现为该行该列为空。
4. 列：对所有单元格的 `[x0,x1]` 区间做重叠聚类得到列锚点，按最大重叠归属；居中排版的列也能正确归位。
5. 表头判定：首行全为非数值短标签 → 作表头；否则用空表头占位，数据行一条不丢。

## 8. 公式

在行装配**之前**处理，避免上下标碎片污染正文：

- 每个基线带内按 x 聚类（间隙 >2 em 断开），簇内数学字体（CMMI/CMSY/MSBM/STIX…）占比 ≥45% 且 ≥3 个字形的簇视为公式候选；
- 同带或相邻带、位于其右侧的 `(N)` 为编号；无编号不收录；
- 邻带的上下标按 `|Δy| ≤ 1.35 body` 且 x 落在公式范围内回收；
- 另设兜底：整段公式为单一文本对象（Word/matplotlib 导出）时，若带内仅一个 `(N)` 且文本含 `=`，同样收录。

## 9. 段落与章节

- 段内合并：同栏、字号一致、行距 <0.62 行高，且不满足下述任一断段条件。
- 断段条件：下一行相对本栏左边距缩进 >0.75 em；或上一行"明显短"（右侧空白 >45% 栏宽）；或上一行以句末标点结束且下一行以大写/汉字开头；字号跳变；标题行前后。
- 续句保护：上一行未以句末标点结尾且下一行以小写字母开头时，即使上一行偏短也继续合并——避免把被两端对齐拉短的行误切成新段。
- 标题：编号标题（`3.1. …`）按编号点数定级；白名单标题词（Abstract/References/参考文献…）为 1 级；字号 ≥1.12×正文的独行标题为 1 级；粗体短行（≥0.97×正文、≤10 词、不含句内句号）为 2 级。表内小字号（<0.92×正文）永不判为标题。

## 10. 参考文献

从 `References`/`参考文献` 标题后开始，遇附录标题（`A. Object Detection …`）或新的一级标题即停；每条以 `[n]`、`(n)`、`n.`、`Author, A.` 起始切分；若块级切分与标记流不一致（合并或误切），改用标记流整体重切，保证条数与顺序。

## 11. 证据绑定

- 每个语义字段记录其来源行对象的 `(page, bbox)`，输出时按 `scale = 页宽(pt)/页宽(pdf2xml 单位)` 换算成 PDF point。
- 同一字段多块时逐块输出；表格额外附带题注块，图额外附带 `<image>` 包围盒（若存在）。
- `scripts/selfcheck.py` 反向校验：字段 ↔ evidence 双向存在，页码在范围内，bbox 不反向。

## 12. 参数一览

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `body` | 众数字号 | 所有阈值的基准 |
| pass1 gap | 1.25 em | 求栏缝用的保守行装配 |
| pass2 gap | 6 em（受栏缝与字号差保护） | 行内数学/大空格回收 |
| 栏缝宽度 | 0.4%–11% 页宽 | 排除边距与参差空白 |
| 栏闭合比例 | ≥50% | 排除单栏页伪栏缝 |
| 页眉带 | 上 9% / 下 11.5% | 位置判据 |
| running head 重复率 | ≥35% 页面 | 跨页重复判据 |
| 图注续行行距 | <0.85 行高 | 图注块边界 |
| 段内行距 | <0.62 行高 | 段内合并 |
| 短行阈值 | 右侧空白 >45% 栏宽 | 段落结束 |
