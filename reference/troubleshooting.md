# 故障排查表

按"看到的现象"查，不要凭感觉改参数。

## 1. 阅读顺序类

| 现象 | 可能原因 | 处置 |
| --- | --- | --- |
| 段落中左右栏交叉出现 | 该页未检出栏缝（`parse_debug.json` 的 `gutters[n]` 为空） | 看该页正文行数：<8 行时算法按单栏处理；若确为双栏，用 `--debug` 查 `gutters_pass1`，多为该页正文极少（整页图/表） |
| 段落内部出现"上行接下栏" | pass 2 把跨栏片段合并成一行 | 检查该页 `gutters` 是否为空；空则栏缝未识别，见上一条 |
| 通栏标题被拆进左栏 | 未识别为 spanning 行 | 确认标题 `x0 < 栏缝左界` 且 `x1 > 栏缝右界`；若标题恰好只覆盖一栏，则它确实不是通栏 |
| 三栏期刊只识别出两栏 | 中缝过宽（>11% 页宽）或过窄 | 属已知边界，结果仍可用；在 `uncertain_items` 记录 |

## 2. 页眉页脚类

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| 期刊名/卷期混入 abstract | 该行不在页眉带（>9% 页高） | 属排版异常（横幅下沉），可在 `parse_debug.json` 的 `marginalia` 里确认未被判定，人工在报告里注明 |
| 首页大标题被当页眉删掉 | 位置判据误伤 | 已有保护（首页 + 字号 ≥1.35×正文不删）；如仍发生，检查正文是否被误判为其他字号 |
| 页码留在正文 | 页码非独立行（与正文同 y） | 罕见；记录到 `uncertain_items` |

## 3. 表格类

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| `markdown` 为空但 `caption` 有内容 | 单元格无法聚成 ≥2 列 | 该表多为无框线稠密表；结果里保留 caption 并记 uncertain，不要手填 |
| 表格列被合并 | 列间距 <2 em | 已知边界；`caption` 与数据行仍在，可用于人工核对 |
| 表格内容跑到正文 section 里 | 表题缺失，区域无法锚定 | 无表题的表无法定位；`sections` 中出现表格碎片时属预期，报告中说明 |
| 表格跨页只取到一半 | 下一页表体前有正文行 | 续接只取下一页上半部的非正文行；若失败，记 uncertain |

## 4. 公式类

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| 公式未收录 | 无编号，或数学字形 <3 | 只收带编号展示公式，这是契约；行内公式本就不收 |
| `raw_text` 缺字符 | 上下标超出邻带窗口 | 检查该公式是否跨两行；可接受，报告中说明 |
| 公式把正文切碎 | 公式识别误吞正文行 | 只有当行内数学字体占比 ≥45% 才判为公式，正常不会发生；若发生，记 uncertain 并保留原文分块 |

## 5. 文本层类

| 现象 | 状态 | 说明 |
| --- | --- | --- |
| `(cid:123)` / `U+FFFD` 少量出现（<20%） | `partial_complete` | 字体部分缺 ToUnicode；原样保留不乱猜，`uncertain_items` 给出页码 |
| 全篇字形无 Unicode 映射（可读字符 <20%，私有区码位） | `cannot_judge` | 例：部分中文 PDF 用 CID 字体且未写 ToUnicode。此时后端只能取到码位号，任何"还原"都是猜字；需原字体映射或 OCR |
| 可抽字符数≈0、页面全是图片 | `cannot_judge` | 无文本层，需 OCR；本 Skill 不做 OCR |
| PDF 加密 | `reject` | 空口令打不开即拒绝，不做暴力破解 |
| 页面文字只占半幅且无栏缝 | 可能 `partial_complete` | 该页多为整页图或特殊版式 |

## 6. 运行环境类

| 报错 | 处置 |
| --- | --- |
| `missing binary: pdftohtml` | 镜像缺 poppler-utils；`pdftohtml` 是本 Skill 的硬依赖 |
| `pypdf unavailable` | 仅影响页数/加密/乱码探测；主流程仍可跑，但加密检测退化 |
| `numpy` 缺失 | 拦缝检测回落到计数版判据，精度略降（脚本自动降级，不报错） |
| 输出目录不可写 | 换 `--out-dir /app/work` 后再拷贝 |

## 7. 自检失败对照

| selfcheck 报错 | 含义 | 处置 |
| --- | --- | --- |
| `fields without evidence` | 有内容没绑证据 | 重跑解析；仍失败则把该项记入 `uncertain_items` 并清空该字段（宁缺勿造） |
| `target_key ... does not exist` | 证据指向不存在的下标 | 重跑；说明索引在写入后被改动 |
| `run_status=reject must not carry parsed content` | 状态与内容矛盾 | 重跑；确属加密就应清空内容 |
| `success with non-empty uncertain_items` | 状态过于乐观 | 改为 `partial_complete` |
